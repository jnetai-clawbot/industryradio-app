# Industry Radio App - Changes Log

## 2026-08-27 - v1.0.0 (Initial Release)

### Project setup
- Created new project at /home/jay/Documents/Scripts/AI/OpenCode/IndustryRadio-App/
- New GitHub repository: https://github.com/jnetai-clawbot/industryradio-app
- Dedicated keystore generated at app/keystore/keystore.jks (alias: industryradio, CN=Industry Radio)
- Keystore stored as base64 in GitHub Actions secrets: KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD
- Same keystore will be reused for all future updates so the app can update without uninstall
- Build is via GitHub Actions only (prime directive) - NEVER local builds

### App features (dark themed, centered, spaced bottom)
- MainActivity: auto-opens the radio site on launch; "Open Radio", Settings and About buttons
- Back button menu option dialog: Goto Settings, About, Exit App, Back To App (Cancel)
- WebView wrapper loads https://industryradio.co.uk (responsive; fullscreen mobile view)
- Back button in webview: navigates WebView history, then offers the options menu
- SettingsActivity: allows updating the site URL, with validation and Reset to default
- AboutActivity: full version number (matches GitHub release tag v1.0.0), "Made by jnetai.com"
- "Check for Updates" button queries GitHub latest release via API; on any failure it falls
  over to opening the GitHub releases page link
- "Share App" button shares the GitHub releases link
- Internet permission included for site + update checks
- Bottom padding/spacing added so buttons/elements at the bottom are never cut off

### Error handling / debugging (persistent)
- DebugLogger.kt: timestamped, tagged, in-memory ring-buffer log (500 entries) with full
  stack traces on failures
- ErrorCodes.kt: central permanent error codes used everywhere (Settings, WebView, Update,
  Share, Main, ExitMenu, Nav)
- Every activity wraps UI setup in try/catch, logs with error codes, shows user feedback
- WebView errors log error codes and show a readable error message

## 2026-08-27 - v1.1.0 (Update)

### Fix: LiveChat box went to signup page instead of loading the chat
- Enabled first-party AND third-party cookies via CookieManager
  (LiveChat relies on cookies/session; without them it bounces to signup)
- Enabled multiple windows + JavaScript window.open handling: onCreateWindow now
  routes LiveChat popup windows back into the main WebView so chat loads in-app

### Fix: menu/dialog text disappearing (should be dark bg + light text)
- Added explicit dark dialog theme overlay ThemeOverlay.IndustryRadio.Dialog
  (dark surface background, light text, visible list items, dark force off)
- Applied the overlay to the exit menus and the WebView JS alert dialog
- New IndustryRadioApp Application class applies dark theme BEFORE any activity
  is created, eliminating mid-launch theme-recreation text/color glitches
- SettingsManager.init is now idempotent (runs once in Application.onCreate)

### Change: launcher / app logo now shows the letters IR
- Replaced vector circle-only icon with a full blue-circle + white "IR" logo
- Adaptive foreground (drawable/ic_launcher_foreground.png) + legacy mipmaps
  (mdpi..xxxhdpi, ic_launcher + ic_launcher_round)
